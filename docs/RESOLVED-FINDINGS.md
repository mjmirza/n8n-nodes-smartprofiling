## Not pinned by a test

- 0.1.10, `9cbe930`. The public repository move, nex8n signed publishing, HTTP helper migration and all three legacy error status shapes, the switch to n8n sleep, the Speaker label and channel operation order, and the official lint configuration have no dedicated regression assertions.
- 0.1.11, `51a82b3`. Scanner acceptance through error rewrapping, masking the continuation token and pinning the node CLI version have no regression tests under test/.
- 0.2.0, `5c26446`. The descriptions of API options that are not yet applied and the wiring of behavior tests into npm test, CI and publishing have no direct regression assertions. Plain and Paragraph transcript layouts are not asserted. The zero-credit credential claim was corrected in 0.3.2 and is not a resolved finding.
- 0.3.0, `65e3b79`. The README and token description explaining that the API ignores continuation tokens are not directly asserted. The added regression coverage is validation work rather than another resolved finding.
- 0.3.1, `191d1d1`. The HTTP error test names message preservation but only asserts the status code. The realistic HTTP mock is validation work rather than a separately pinned fix.
- 0.3.3, `ec2c7ce`. The README examples adding Split Out on data.videos have no regression test.
- 0.4.1, `c51457f`. The Node 20.19 minimum and CI runtime matrix have no direct regression assertions. The retry tests assert count bounds but do not assert the initial delay bounds of 100 to 30000 ms.
- 0.4.4, `3391fb1`. The growth history test asserts the tracking prerequisite but does not assert the daily snapshot wording. The playlist description test asserts the first page warning but does not assert the usual limit of 100 videos.
